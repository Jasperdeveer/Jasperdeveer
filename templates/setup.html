{# Stap 1: Tailscale #}
1 Tailscale installeren — veilige verbinding thuis↔iPhone

Tailscale maakt een privénetwerk tussen jouw computer en iPhone. Je e-mail verlaat nooit je thuisnetwerk. Gratis voor persoonlijk gebruik.

  1. Ga naar tailscale.com/download en installeer Tailscale op je computer (Mac of Windows).
  2. Installeer de Tailscale-app op je iPhone via de App Store.
  3. Log in op beide apparaten met hetzelfde Tailscale-account (gratis via Google of GitHub).
  4. Zet op je computer in de terminal (Mac) of Command Prompt (Windows): 
    tailscale serve --bg 5000
    Dit geeft je een veilige HTTPS-adres, bijv.: https://mijnpc.staart-xyz.ts.net
  5. Noteer dat adres — je hebt het nodig bij stap 2 en 3.
{# Stap 2: Azure #}
2 Azure App Registratie — toegang tot jouw inbox

Microsoft vereist dat je een gratis "App Registratie" aanmaakt zodat de app namens jou je inbox mag lezen. Jij beslist zelf welke rechten je geeft.

  1. Ga naar portal.azure.com → zoek op "App registraties" → + Nieuwe registratie.
  2. Naam: bijv. Spam Uitschrijver
    Accounttype: "Persoonlijke Microsoft-accounts"
  3. Redirect URI (plak jouw Tailscale-adres in):
    https://<jouw-tailscale-adres>/callback
  4. Klik op Registreren.
  5. Kopieer de Toepassings-ID (Client ID) van de overzichtspagina.
  6. Ga naar Certificaten en geheimen → + Nieuw clientgeheim → kopieer de Waarde (niet de ID!).
{# Stap 3: .env #}
3 .env bestand invullen

Maak een bestand .env aan in de map van de app met deze inhoud: 

AZURE_CLIENT_ID=<jouw client-id>
AZURE_CLIENT_SECRET=<jouw client-secret>
AZURE_TENANT_ID=common
REDIRECT_URI=https://<jouw-tailscale-adres>/callback
FLASK_SECRET_KEY=<een lange willekeurige string, bijv. 40+ tekens>
HTTPS_ONLY=true
SESSION_HOURS=8

Genereer een veilige sleutel via: python -c "import secrets; print(secrets.token_hex(32))"

{# Stap 4: starten #}
4 App starten

Mac / Linux:

./start.sh

Windows:

start.bat

Open daarna je Tailscale-adres in Safari op je iPhone en klik op Inloggen met Microsoft.
Installeer de app via het Deel-icoon → "Zet op beginscherm".
